# OOP Quiz – 1.000 câu C#

## Các tệp

- `index.html`: giao diện HTML có cấu trúc, không nhúng dữ liệu lớn.
- `style.css`: toàn bộ CSS.
- `app.js`: xử lý bộ lọc, chọn câu, nộp bài, chấm điểm và xem lại.
- `questions.js`: ngân hàng 1.000 câu hỏi có lời giải (200 lý thuyết, 800 code).

## Triển khai GitHub Pages

1. Upload **cả bốn tệp** vào thư mục gốc repository `299quanglinh/oop_gk` (chọn Add file → Upload files). Không upload riêng index.html.
2. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
3. Mở `https://299quanglinh.github.io/oop_gk/` sau khi GitHub thông báo triển khai thành công.

## Lưu ý

Đây là bản tái cấu trúc mã để dễ đọc, vẫn dùng ngân hàng câu hỏi của bản cũ. Việc tái cấu trúc không đồng nghĩa với xác minh tính chính xác học thuật của toàn bộ 1.000 câu.
